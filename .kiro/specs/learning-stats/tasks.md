## Implementation Notes

- 共通: 部分木での絞り込みは DB 側で行い、ID 一覧をクライアントへ返さない（API 経由は 1,000 行で切り捨て）。ページ分割は fetchAllPages でサーバーと同じ一意な順序を使う。日時は文字列比較せず Date.parse で比べる。他 feature のコンポーネントは import しない（design の Allowed Dependencies のみ）。DB の保護テーブル（answers 等）は FK が on delete restrict。E2E は seed を書き換えず、実行ごとに接頭辞付きのデータを作って片付ける（解答の作成は record_answer RPC、後片付けは e2e/quiz-db.spec.ts の方式）。報告の STATUS は決まった値にする。
- 書式: prettier 設定ファイルはないが、既存コードは単一引用符・行幅 120（`npx prettier --single-quote --print-width 120`）。既定の二重引用符にしない。
