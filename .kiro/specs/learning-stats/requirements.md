# Requirements Document

## Project Description (Input)

所有者は、どの設問・キーワードが弱いか、どれだけ出題されたかを全体として把握できない。現状は出題セッションが解答履歴を記録し、設問ごと・キーワードごとの正答数・出題数・正答率を集計しているが、それを一覧・分布として見る手段がない。所有者がスマートフォンで、科目とキーワードの範囲を選び、設問ごと・キーワードごとの正答率と出題回数の分布をヒストグラムで確認し、気になる区間に含まれる設問・キーワードを確認できるようにする。

## Introduction

本機能は、出題セッションが提供する設問ごと・キーワードごとの集計値を区間（ビン）に分け、正答率と出題回数の分布をヒストグラムで表示する「学習統計」を提供する。キーワードの集計は、そのキーワードと配下の階層に紐づく問題すべてを対象とする（集計の定義は出題セッションのものに従う）。科目とキーワード範囲で対象を絞り込み、区間を選ぶと、その区間に含まれる設問・キーワードの一覧へ掘り下げられる。統計画面はモバイル優先とする。

## Boundary Context

- **In scope**: 統計画面への導線、科目とキーワード範囲による絞り込み、設問ごと・キーワードごとの正答率と出題回数のヒストグラム、区間の定義と区間への振り分け、区間からの設問・キーワード一覧への掘り下げ、件数が多い場合の欠落のない表示
- **Out of scope**: 解答・出題の処理、SRS 状態の更新、設問ごと・キーワードごとの正答数・出題数・正答率の計算（出題セッション）、統計や集計値の出力（取込・出力機能）、問題・キーワードの編集（問題カタログ）、期間による絞り込みや推移の表示
- **Adjacent expectations**: 出題セッションの集計値（正答数・出題数・正答率、「わからない」と「？」エリアの解答の数え方、無効化・削除された問題の除外、キーワード配下の問題を重複なく数えること、出題数0の正答率は値なしとすること）をそのまま使い、本機能で再計算しない。キーワード階層は問題カタログのものを使う。導線・テーマ・全件取得・認証は基盤機能のものを使う

## Requirements

### Requirement 1: 統計画面への導線と絞り込み

**Objective:** 所有者として、スマートフォンから統計画面を開き、見たい科目とキーワードの範囲を選びたい。それにより関心のある範囲だけの分布を確認できる。

#### Acceptance Criteria

1. 学習統計は、ログイン済みの所有者に、学習の区分の導線として統計画面への入口を表示する
2. 所有者が統計画面を開いたとき、学習統計は所有者の削除されていない科目の一覧を選択肢として表示する
3. 所有者が科目を選んだとき、学習統計はその科目のキーワード階層を階層の深さが分かる形で表示し、「科目全体」または任意の深さのキーワード1つを範囲として選べるようにする
4. 所有者が範囲を選んだとき、学習統計は選んだ科目と範囲の内容でヒストグラムを表示し直す
5. 所有者が科目と範囲を選んだ状態で画面を再読み込みしたとき、または同じ URL を開いたとき、学習統計は同じ科目・範囲・表示内容を復元する
6. 未ログインの利用者が統計画面を開いた場合、学習統計は統計を表示せずログイン画面へ誘導する
7. 科目が1件もない場合、学習統計は科目がないことを表示し、ヒストグラムを表示しない

### Requirement 2: 設問ごとのヒストグラム

**Objective:** 所有者として、範囲内の設問の正答率と出題回数の分布を見たい。それにより弱い設問や出題が偏っている設問の量を把握できる。

#### Acceptance Criteria

1. 所有者が設問の統計を表示したとき、学習統計は範囲内の設問を設問ごとの正答率で区間に分けたヒストグラムを表示する
2. 所有者が設問の統計を表示したとき、学習統計は範囲内の設問を設問ごとの出題回数で区間に分けたヒストグラムを表示する
3. 学習統計は、キーワードを範囲に選んだ場合、そのキーワードと配下のすべてのキーワード（途中のノードを含む）のいずれかに紐づく設問を対象とし、科目全体を選んだ場合はその科目の設問すべてを対象とする
4. 学習統計は、無効化または削除された設問をヒストグラムと件数に含めない
5. 学習統計は、出題回数が0の設問を正答率のヒストグラムの区間に含めず、「未出題」の件数として区間とは別に表示する
6. 学習統計は、ヒストグラムとあわせて対象の設問数を表示する
7. 範囲内に対象の設問が1件もない場合、学習統計はヒストグラムの代わりに対象の設問がないことを表示する

### Requirement 3: キーワードごとのヒストグラム

**Objective:** 所有者として、範囲内のキーワードの正答率と出題回数の分布を見たい。それにより弱い概念のまとまりを把握できる。

#### Acceptance Criteria

1. 所有者がキーワードの統計を表示したとき、学習統計は範囲内のキーワードをキーワードごとの正答率で区間に分けたヒストグラムを表示する
2. 所有者がキーワードの統計を表示したとき、学習統計は範囲内のキーワードをキーワードごとの出題回数で区間に分けたヒストグラムを表示する
3. 学習統計は、各キーワードの正答率と出題回数として、そのキーワードと配下の階層に紐づく出題対象の設問すべてを、同じ設問を重複して数えずに集計した値を使う
4. 学習統計は、キーワードを範囲に選んだ場合はそのキーワード自身と配下のすべてのキーワードを対象とし、科目全体を選んだ場合はその科目のキーワードすべてを対象とする
5. 学習統計は、配下を含めて出題対象の設問が1問も紐づかないキーワードをヒストグラムと件数に含めない
6. 学習統計は、出題回数が0のキーワードを正答率のヒストグラムの区間に含めず、「未出題」の件数として区間とは別に表示する
7. 学習統計は、ヒストグラムとあわせて対象のキーワード数を表示する
8. 範囲内に対象のキーワードが1件もない場合、学習統計はヒストグラムの代わりに対象のキーワードがないことを表示する
9. 所有者が設問とキーワードの表示を切り替えたとき、学習統計は選んだ科目と範囲を保ったまま表示を切り替える

### Requirement 4: 区間の定義

**Objective:** 所有者として、どの範囲・どの時点でも同じ基準の区間で分布を見たい。それにより範囲どうしや時間をおいた比較ができる。

#### Acceptance Criteria

1. 学習統計は、正答率の区間を0%から100%までの10%刻みの10区間とし、各区間は下限を含み上限を含まず、正答率100%は最後の区間（90%〜100%）に含める
2. 学習統計は、出題回数の区間を、「0回」の区間と、k = 1, 2, 3, … について「2^(k-1) 回以上 2^k − 1 回以下」の区間（1回、2〜3回、4〜7回、8〜15回、…）とし、「0回」から対象の最大の出題回数を含む区間までを表示する
3. 学習統計は、対象の各設問・各キーワードを、指標ごとにちょうど1つの区間（正答率の場合は区間または「未出題」）に数え、区間の件数の合計を対象の件数と一致させる
4. 学習統計は、件数が0の区間も省略せずに表示する
5. 学習統計は、各区間に、区間の範囲を示すラベルと件数を数値で表示する

### Requirement 5: 区間からの掘り下げ

**Objective:** 所有者として、気になる区間に含まれる設問・キーワードを具体的に知りたい。それにより弱い設問の見直しや重点的な学習につなげられる。

#### Acceptance Criteria

1. 所有者が件数1件以上の区間（「未出題」を含む）を選んだとき、学習統計はその区間に含まれる設問またはキーワードの一覧を表示する
2. 学習統計は、設問の一覧の各行に、問題文の冒頭、正答数、出題数、正答率を表示する
3. 学習統計は、キーワードの一覧の各行に、キーワードの階層パス、対象の設問数、正答数、出題数、正答率を表示する
4. 学習統計は、一覧を正答率の低い順（出題数0は先頭）、同じ正答率では出題数の多い順に並べ、同値でも毎回同じ順で表示する
5. 学習統計は、一覧の件数を区間の件数と一致させる
6. 所有者が設問の一覧の行を選んだとき、学習統計はその問題を問題カタログの編集画面で開く
7. 所有者が一覧を閉じたとき、または別の区間・範囲を選んだとき、学習統計は前の一覧を表示しない
8. 学習統計は、件数が0の区間を選べないようにする
9. 学習統計は、正答率・出題数の表示で、出題数0のものを「未出題」と表示する

### Requirement 6: 件数が多い場合の正確性

**Objective:** 所有者として、問題やキーワードが多くても欠けのない統計を見たい。それにより統計を信頼して判断できる。

#### Acceptance Criteria

1. 対象の設問またはキーワードが1,000件を超える場合でも、学習統計はすべての設問・キーワードを区間の件数に含め、欠落も重複もなく表示する
2. 区間に含まれる設問またはキーワードが1,000件を超える場合でも、学習統計は掘り下げの一覧にすべてを欠落も重複もなく表示する
3. 学習統計は、各区間の件数と掘り下げの一覧で、出題セッションが記録した最新の解答を反映した値を表示する
4. 一覧の一部だけを取得できた場合、学習統計は部分的な一覧を表示せず、取得に失敗したことを表示する

### Requirement 7: モバイル表示・アクセシビリティ・エラー

**Objective:** 所有者として、スマートフォンで見やすく、誰でも操作できる統計画面を使いたい。それにより外出先でもすぐに弱点を確認できる。

#### Acceptance Criteria

1. 学習統計は、統計画面をモバイル幅（390px 程度）で横スクロールなく表示し、区間のラベルと件数が重ならずに読めるようにする
2. 学習統計は、区間の選択、表示の切り替え、範囲の選択、一覧の操作をキーボードだけで行え、フォーカスの位置が見えるようにする
3. 学習統計は、各区間の操作領域を44px 相当以上とする
4. 学習統計は、ヒストグラムの各区間の範囲と件数を、色や棒の長さに頼らずに文字でも読み取れるようにし、支援技術にも区間の範囲・件数・選択状態を伝える
5. 学習統計は、ライトとダークの両方のテーマで、ヒストグラムの棒・文字・選択状態を背景と区別できるコントラストで表示し、正解・不正解の色やエラーの色をヒストグラムの棒に使わない
6. 統計の取得に失敗した場合、学習統計は失敗した内容を日本語で表示し、再試行できるようにする
7. 統計の取得中の間、学習統計は読み込み中であることを表示する
